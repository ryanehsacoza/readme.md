# Ryan Cowan Living Hero 2.0.0

## Standalone HTML preview
Open `HTML-PREVIEW/index.html` in a browser. Move your pointer directly over Ryan, the children, the baby, the family scene or the coastline. A glowing region (not a floating button) identifies the selected area. Voice/audio will attempt to start on hover. Browsers often require one user gesture first; click Enable audio if needed.

## WordPress plugin
Install `ryan-cowan-hero-wordpress-plugin-v2.0.0.zip` via Plugins > Add New > Upload Plugin. Configure Settings > Ryan Living Hero. Use shortcode `[ryan_cowan_hero]` or embed the public scene URL displayed on the settings page in Depicter iframe element.

## Configuration
Configure each region center x/y (percentage), width/height, speech phrase, pitch, speed, volume; adjust accent, hover scale, delay, locale, available voice name, motion, stop-on-exit, audio mute and hint visibility. Configuration is sanitized on save and stored as WordPress option `rch_settings_v2`. Reset option is available.

## Limitations
Synthetic voices, not real persons. No true facial viseme system or 3D skeletal rig. Depicter iframe integration is supported as an embedding route, not native editable Depicter slides. Browser autoplay and exact voice timbre cannot be guaranteed.
